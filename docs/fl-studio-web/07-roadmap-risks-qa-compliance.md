## 1. 阶段路线图

### Phase 0 · 技术验证与设计（2–4 周）

| 目标 | 交付物 | 退出标准 |
|---|---|---|
| 验证浏览器音频极限 | AudioWorklet 原型：64 复音 + 8 轨 + 4 FX | 中端笔记本 48kHz 无 dropout，CPU <60% |
| 验证时间线渲染 | Canvas 原型：500 轨/10k 音符 | 滚动/缩放 ≥55fps |
| 验证工程 I/O | ZIP 读写 + IndexedDB 自动保存原型 | 50MB 工程 3s 内加载 |
| 验证导出 | OfflineAudioContext 渲染 WAV | 5 分钟工程 ≤2 分钟 |
| 确定设计语言 | 设计 tokens、主界面线框 | 评审通过 |

**产出**：技术 Spike 报告、性能基线、架构决策确认（ADR-01/02/03）。

### Phase 1 · MVP（8–12 周）

范围：能完成"新建 → 鼓点/旋律 → 编排 → 导出 WAV"。

- Channel Rack + Step Sequencer（512 步）
- Piano Roll（基础音符编辑 + Slide/Porta）
- Playlist（单 Arrangement、Pattern/Audio/Automation Clip）
- Mixer（基础路由、10 slot、EQ/Comp/Limiter/Reverb/Delay）
- 乐器：Sampler、Triple Osc、808/909 鼓组、Piano、GM Lite
- 自动化 Clip（基础曲线）
- 工程保存/自动保存/崩溃恢复
- WAV 导出（Song/Pattern）
- 中英双语基础框架

**退出标准**

- AC-01/02/03/04/05/07/08 全部通过。
- 30 分钟 soak test 无 dropout。
- 4 浏览器矩阵可完成核心流程（Safari 允许功能降级）。

### Phase 2 · v0.5（10–14 周）

- Piano Roll 高级：Ghost Notes、量化、Chord Stamp、Scale Snap、事件编辑器完善
- Playlist：多 Arrangement、Track Mode、Performance Mode、切片/淡入淡出
- Mixer：发送/侧链/PDC、分轨导出、更多表
- 效果器 25+：Multiband、Maximus、Convolver、Vocoder、Distructor 等
- 乐器 30+：FPC、Slicex、Granulizer、DirectWave、FL Keys、Sawer、PoiZone、Plucked、Sakura、Drumaxx 等
- 音频录制 + Edison 基础
- MIDI 设备 + MIDI 文件导入/导出
- 20 鼓组、管弦 Lite
- MP3/FLAC 导出
- 自动保存版本历史、快捷键自定义

**退出标准**

- AC-06/09/10 通过；CPU 基准达标；音频回归套件 ≥30 例。

### Phase 3 · v1.0（12–16 周）

- 乐器 54 个 Generator 等价/100+ 定义、GM 128 全音色、60 鼓组

**退出标准**

- 全部 AC 通过；NFR 指标达标；合规清单签署；发布候选（RC）7 天无 P0 缺陷。

### Phase 4 · v1.x（持续）

## 4. QA 策略

### 4.1 测试金字塔

| 层级 | 占比 | 内容 |
|---|---|---|
| 单元 | 60% | 时间数学、TempoMap、路由、PDC、DSP、schema、迁移 |
| 集成 | 25% | 编辑 → 音频事件 → 渲染；保存 → 加载 → 一致 |
| 端到端 | 10% | Playwright：新建/编曲/保存/导出 |
| 探索/人工 | 5% | 交互手感、音频听感、兼容性 |

### 4.2 音频回归（核心）

- 固定工程 + 固定随机种子 → 离线渲染 → 与基线比较。
- 指标：RMS、峰值、频谱质心、THD、RT60、增益包络。
- 容差：浮点 ±0.5dB / 频谱 ±1%；超出即失败。
- 覆盖：合成器、采样器、EQ、动态、延迟、混响、侧链、PDC、导出格式。

### 4.3 浏览器与设备矩阵

| 浏览器 | 版本 | 优先级 |
|---|---|---|
| Chrome | 最新 + 前 2 大版本 | P0 |
| Edge | 最新 | P0 |
| Firefox | 最新 | P1 |
| Safari (macOS/iOS) | 17+ | P1 |
| Chrome Android | 最新 | P2 |
| Safari iPadOS | 17+ | P2 |

设备：中端 Windows 笔记本、MacBook Air M1、Chromebook、iPad、Android 中端机。

### 4.4 性能基准

- 工程 A：64 复音合成器 + 16 轨 + 4 FX/轨。
- 工程 B：500 轨 Playlist + 10k 音符（UI）。
- 工程 C：200 采样 + 1 小时时间线（内存/加载）。
- 工程 D：5 分钟编排（导出时间）。
- 每次合并跑 A/B；每周跑 C/D；发布前跑全矩阵。

### 4.5 安全与健壮性

- Fuzz：`.flw` ZIP、project.json、MIDI、SF2、图片（BeepMap）。
- 边界：空工程、超大值、NaN、负 tick、循环引用、重复 ID。
- 故障注入：音频设备断开、存储配额满、Worker 崩溃、网络中断（协作）。
- 静态：依赖漏洞扫描、许可证扫描、CSP 检查。

### 4.6 发布门禁

- 0 个 P0/P1 缺陷；P2 有明确豁免。
- 全部 AC 通过；NFR 指标达标。
- 音频回归全绿；性能基准无回退 >10%。
- 合规清单签署；隐私政策/许可证页更新。
- RC 观察 7 天。

## 5. 合规清单

### 5.1 商标与视觉

- [ ] 产品名称、Logo、图标为原创，未使用 FL Studio/Image-Line 商标。
- [ ] UI 布局参考工作流，但视觉资产（图标、皮肤、字体）原创。
- [ ] 不宣称"官方"或"FL Studio 替代品"造成混淆；使用"FL 风格工作流"描述需谨慎。
- [ ] 域名/应用商店名称检索无冲突。

### 5.2 音频内容

- [ ] 所有采样有来源、许可证、哈希记录（`licenses/assets.json`）。
- [ ] 不使用 FL Studio 安装目录中的采样、预设、IR、演示工程。
- [ ] CC BY 素材保留署名；CC0 保留来源记录。
- [ ] 用户录音默认本地、不用于训练/分析。
- [ ] 提供"删除/替换素材"能力，满足分发合规。

### 5.3 代码与库

| 依赖 | 许可证 | 备注 |
|---|---|---|
| React / Vite / Zustand / Zod | MIT | 允许商用 |
| Yjs | MIT | 协作 |
| lamejs | LGPL | 动态链接/独立模块，需核验分发方式 |
| libflacjs | BSD/GPL? | **必须核验**；优先 WASM FLAC 替代 |
| @tonejs/midi | MIT | MIDI 解析 |
| Rust wasm-bindgen | MIT/Apache-2.0 | WASM |
| WebCodecs | 浏览器内置 | AAC/Opus 编码受 OS/浏览器许可影响，需核验 |

- [ ] 生成 SBOM；CI 执行许可证扫描。
- [ ] 避免 GPL 代码进入核心闭源部分；LGPL 库以独立模块动态加载。
- [ ] MP3 专利已过期（2017），但编码器实现许可证仍需核验。

### 5.4 隐私与数据

- [ ] 默认本地存储；云功能显式开启并告知。
- [ ] 遥测默认关闭或明确同意；不采集音频内容。
- [ ] GDPR/CCPA：导出/删除用户数据；数据处理说明。
- [ ] 儿童使用场景（课堂）：不收集个人信息；教师控制分享权限。
- [ ] 协作房间：访问控制、过期清理、滥用举报。

### 5.5 可访问性

- [ ] WCAG 2.1 AA：对比度、焦点、键盘可达、屏幕阅读器名称。
- [ ] 减少动画选项；色盲友好配色。
- [ ] 缩放 200% 不截断关键控件。

## 9. 附录 A：采样库授权清单

> 用途：把"能不能商用、要不要署名、能不能再分发"落实到每一份素材。上线前逐行签字。
> 状态：**可用**＝许可明确允许商用；**核验中**＝需逐条确认（尤其是"软件内置再分发"条款）；**禁用**＝不进入发布包。

### 9.1 核心与管弦

| 素材库 | 内容 | 许可 | 商用 | 署名 | 再分发（内置到软件） | 状态 |
|---|---|---|---|---|---|---|
| VSCO 2 Community Edition | 管弦（弦/铜/木管/打击） | CC0 1.0 | 允许 | 不强制 | 允许 | 可用 |
| Salamander Grand Piano | 钢琴（Yamaha C5，多力度） | CC BY 3.0 | 允许 | 必须 | 允许（保留署名） | 可用 |
| GeneralUser GS | GM/GS SoundFont | 自定义免费许可（允许软件项目使用） | 允许 | 建议保留 | 允许 | 可用 |
| FluidR3 GM | GM SoundFont | 逐项核验（部分条目来源不明） | 待定 | 待定 | 待定 | 核验中 |
| Sonatina Symphonic Orchestra | 管弦 | CC Sampling Plus 1.0 | 允许（含再分发） | 视条款 | 允许 | 核验中 |
| Salamander 之外的电钢/风琴 | Rhodes/Wurli/Clav | 需逐库核验 | 待定 | 待定 | 待定 | 核验中 |

### 9.2 鼓组、世界乐器与音效

| 素材库 | 内容 | 许可 | 状态 |
|---|---|---|---|
| 自录/自设计鼓组（团队录音棚） | 60 鼓组核心 | 自有版权 | 可用（推荐主力） |
| freesound CC0 精选 | 打击/音效/纹理 | CC0 | 可用（需逐条记录来源 ID） |
| Philharmonia Orchestra 采样 | 管弦补充 | CC BY-NC 系（多数为 NC） | 禁用（NC 不可商用） |
| 各类"免费鼓包"网站 | 鼓 loop | 多为 NC/禁止再分发 | 禁用（除非书面授权） |
| 合成生成 IR（程序生成） | 混响 IR | 自有版权 | 可用（推荐，规避 IR 授权） |
| 开源 IR 库（OpenAIR 等） | 空间 IR | CC BY / CC0 混合 | 核验中（逐条记录） |

### 9.3 处理原则

1. **优先级**：自有录音/自有设计 > CC0 > CC BY > 自定义免费许可 > 禁用。
2. **禁止**：NC（非商用）、ND（禁止演绎）素材不得进入发布包；"免费下载"不等于可再分发。
3. **记录字段**：`id / name / sourceUrl / license / licenseUrl / author / attributionText / sha256 / addedAt`。
4. **可删除性**：每个素材包可独立卸载，卸载后工程以"缺失素材"提示重链。
5. **署名页**：应用内"许可证与素材来源"页自动汇总所有 CC BY 条目。
6. **替换机制**：任何素材均可被用户自有采样替换，避免"素材锁定"。

## 10. 附录 B：导出编码授权方案

| 格式 | 方案 | 许可风险 | 建议 |
|---|---|---|---|
| WAV | 自实现 PCM 写入（16/24/32-bit float） | 无 | **P0 默认** |
| FLAC | WASM libFLAC 或自实现编码 | libFLAC 为 BSD；JS 封装需核验 | P1，优先 WASM |
| MP3 | WASM LAME（编译为独立模块动态加载） | LAME 为 LGPL；需提供源码/可替换 | P1，法务确认后启用 |
| MP3（备选） | 服务端转码 | 无前端许可问题，但有成本与隐私 | 备选 |
| AAC/Opus | WebCodecs `AudioEncoder` | 受 OS/浏览器编解码许可影响，通常由平台承担 | P2，能力检测后启用 |
| OGG Vorbis | WASM libvorbis（BSD） | 低 | P2 |
| 视频（可选） | WebCodecs + MP4 封装 | 容器/编解码许可复杂 | P2，仅"可视化导出" |

**MP3 落地决策（建议）**

1. 1.0 **只发布 WAV**，MP3/FLAC 作为 P1 增量，避免阻塞首发。
2. MP3 采用 **独立 Worker + WASM 编码器**，与主程序通过消息协议交互，满足 LGPL "可替换/可重链接"精神。
3. 在"关于/许可证"页列出编码器名称、版本、许可证与源码获取方式。
4. 若法务否定 LGPL 方案，则改用**服务端转码**或仅提供 AAC（WebCodecs）。
5. 导出页明确标注每种格式的比特率/采样率上限与预计文件大小。
